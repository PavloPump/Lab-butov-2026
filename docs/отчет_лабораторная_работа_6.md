## 2. Описание реализованного приложения

**Назначение приложения:**
Система управления доставкой грузов предназначена для автоматизации процессов логистики, позволяя клиентам создавать заказы на доставку, а водителям — управлять процессом доставки. Приложение обеспечивает прозрачность отслеживания грузов и эффективное взаимодействие между участниками процесса доставки.

**Цели проекта:**
- Автоматизация процессов логистики и доставки грузов
- Обеспечение прозрачности отслеживания заказов
- Упрощение взаимодействия между клиентами и водителями
- Создание интуитивного пользовательского интерфейса

**Реализованный функционал:**

**Для клиентов:**
- Регистрация и авторизация в системе
- Создание заказов на доставку грузов
- Просмотр списка своих заказов
- Отслеживание статусов заказов с цветовой индикацией
- Выход из системы

**Для водителей:**
- Регистрация и авторизация в системе
- Просмотр доступных заказов
- Принятие заказов в работу
- Управление текущими доставками
- Обновление статусов доставки (ожидает → в пути → завершена)
- Отображение информации о доставках

**Технические характеристики:**
- **Платформа:** Веб-приложение (SPA)
- **Язык программирования:** TypeScript
- **Фреймворк:** React 18
- **Сборщик:** Vite
- **Стилизация:** TailwindCSS
- **Архитектура:** Clean Architecture (Layered Architecture)
- **Управление состоянием:** React Context API + Custom Hooks
- **Данные:** Mock данные (имитация backend)

## 3. Архитектурные решения

### Архитектурный подход

Проект реализован с использованием **Clean Architecture (Layered Architecture)**, которая обеспечивает разделение ответственности и независимость слоёв.

### Логическое разбиение на слои

#### 1. Presentation Layer (Слой представления)
- **Ответственность:** Отображение UI, обработка пользовательских действий
- **Компоненты:**
  - React компоненты (Alert, Button, EmptyState, Input, Layout, LoadingSpinner)
  - Страницы приложения (HomePage, LoginPage, RegisterPage, ClientDashboard, DriverDashboard)
  - Маршрутизация (React Router DOM)

#### 2. Business Logic Layer (Слой бизнес-логики)
- **Ответственность:** Бизнес-логика, управление состоянием
- **Компоненты:**
  - Custom hooks (useAuth, useOrders, useDriver)
  - React Context (AuthContext)

#### 3. Data Layer (Слой данных)
- **Ответственность:** Работа с данными, API запросы
- **Компоненты:**
  - DataService (класс для работы с mock данными)
  - Mock данные (пользователи, заказы, доставки)

### Принципы архитектуры

**Разделение слоёв:**
- UI, бизнес-логика и данные изолированы
- Каждый слой имеет чёткую ответственность
- Зависимости направлены от внешних слоёв к внутренним

**Переиспользуемые компоненты:**
- Все UI компоненты переиспользуемы
- Custom hooks изолируют бизнес-логику
- Компоненты типизированы и документированы

**Управление состоянием:**
- React Context API для глобального состояния
- Custom hooks для локальной логики
- localStorage для персистентности авторизации

**Типизация:**
- Строгая типизация TypeScript
- Интерфейсы для всех данных
- Типизированные пропсы компонентов
- Типизированные ответы API

### Схема взаимодействия компонентов

```
User Interface (React Components)
    ↓
Business Logic (Custom Hooks)
    ↓
Data Layer (DataService)
    ↓
Mock Data (In-memory)
```

## 4. Описание пользовательского интерфейса

### Дизайн и стиль

**Цветовая палитра:**
- Основной цвет: индиго (#667eea) для акцентных элементов
- Фон: градиент от светло-голубого к индиго для главной страницы
- Карточки: белый (#ffffff) с лёгкими тенями
- Статусы: цветовая кодировка (жёлтый — ожидает, синий — в процессе, зелёный — завершено)

**Типографика:**
- Заголовки: крупный жирный шрифт для иерархии
- Текст: средний размер для основного контента
- Мелкий текст: для подписей и статусов

**Принципы дизайна:**
- Минимализм: чистый интерфейс без лишних элементов
- Консистентность: единый стиль компонентов
- Отзывчивость: адаптивный дизайн
- Интуитивность: понятная навигация
- Доступность: чёткие контрасты и читаемые шрифты

### Реализованные экраны

**1. Главная страница (Home)**
- Лендинг с описанием системы
- Кнопки входа и регистрации
- Градиентный фон
- Призыв к действию

**2. Страница входа (Login)**
- Форма авторизации с полями email и пароль
- Индикатор загрузки
- Обработка ошибок через Alert компонент
- Ссылка на регистрацию

**3. Страница регистрации (Register)**
- Форма регистрации с полями (имя, email, телефон, пароль)
- Выбор роли (клиент/водитель)
- Индикатор загрузки
- Обработка ошибок через Alert компонент
- Ссылка на вход

**4. Панель клиента (Client Dashboard)**
- Создание новых заказов (форма с полями: откуда, куда, вес, габариты)
- Просмотр списка своих заказов
- Цветовая индикация статусов заказов
- EmptyState для отсутствия заказов
- Кнопка выхода

**5. Панель водителя (Driver Dashboard)**
- Просмотр доступных заказов
- Принятие заказов в работу
- Управление текущими доставками
- Обновление статусов доставки
- EmptyState для отсутствия заказов/доставок
- Кнопка выхода

### UI компоненты

**Alert:**
- Универсальный компонент для отображения сообщений
- Поддержка типов: error, success, warning, info
- Возможность закрытия сообщения

**EmptyState:**
- Компонент для отображения пустых состояний
- Иконки и описания
- Возможность действий из пустого состояния

**LoadingSpinner:**
- Компонент для индикации загрузки
- Настраиваемый размер
- Опциональный текст

**Button:**
- Переиспользуемый компонент кнопки
- Варианты: primary, secondary
- Поддержка disabled состояния

**Input:**
- Переиспользуемый компонент поля ввода
- Поддержка типов: text, email, password, tel
- Автоматическая обёртка с label

**Layout:**
- Компонент обёртка для страниц
- Навигационная панель
- Динамическое отображение в зависимости от роли
